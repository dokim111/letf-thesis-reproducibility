# 경제학 논문 계산 코드

「국내 단일종목 레버리지 ETF의 리밸런싱 수요와 순설정의 상쇄: 되먹임 모형과 측정」의 계산을 위한 공개용 코드입니다. 경제학 원고 v17에 사용된 계산 로직을 보존했습니다.

이 폴더에는 계산 스크립트와 실행 안내만 포함합니다. **KRX 원자료는 포함하지 않으므로 저장소를 내려받는 것만으로 계산을 실행하거나 모든 결과를 재현할 수는 없습니다.** 필요한 입력 파일을 별도로 확보하고 아래 안내에 맞춰 준비해야 합니다.

- [실행 방법·입력 자료 명세·논문 표와의 대응](replication/README.md)
- `replication/replicate.py`: 표 3–8, 표 10의 입력 지표, 5.2절 보조 회귀
- `replication/accounting_sensitivity.py`: 표 9 및 회계적 민감도 분석
- `replication/verify_intro_drawdown.py`: 서론의 지정된 두 날짜 사이 종가 수익률
- `replication/requirements.txt`: 계산에 사용된 Python 패키지 버전

공식 제출 서류, 개인 식별·연락 정보, 원고 조판 코드, 내부 검토 기록은 이 공개 묶음에 포함하지 않습니다. 표의 인쇄 형태와 그림 1–2를 자동으로 생성하는 절차도 포함하지 않습니다. 코드 실행 결과는 계산값이며, 논문의 해석·가정·증명을 대체하지 않습니다.
