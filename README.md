# 레버리지 ETF 연구 재현자료

경제학·수리과학·통계학 학부 졸업논문에 사용한 계산 코드와 재현 안내입니다. 작성자: 김도연. 자료 버전: **2026-11-19-v22**.

## 세 연구의 구분

| 분야 | 계산 대상 | 공개 내용 |
|---|---|---|
| [경제학](1_경제학/README.md) | 리밸런싱과 순설정을 반영한 노출 조정액 | 계산 코드 3개, 입력 명세, 표와 코드의 대응 |
| [수리과학](2_수리과학/README.md) | 로그감쇠의 근사오차, 극값과 차수별 전이 임계값 | 검산 코드 6개, 이론 상수와 검산 출력 |
| [통계학](3_통계학/README.md) | 비대칭 정보의 추가 예측력과 사양 민감도 | 분석·표 생성 코드 12개, 집계 결과, 실행 안내 |

대응 원고는 경제학 v17, 수리과학 졸업논문 초기본 v0.3, 통계학 졸업논문 초기본 v0.4입니다. 파일명의 버전은 편집본을 구별하기 위한 것으로 학과 심사나 제출 완료를 뜻하지 않습니다.

## 바로 실행할 수 있는 범위

수리의 이론 검산과 통계의 **집계 결과에서 표를 다시 생성하는 작업**은 이 저장소의 파일로 실행할 수 있습니다. 아래는 대표 명령이며, 전체 순서와 환경은 각 폴더의 README를 따릅니다.

```bash
cd 2_수리과학
python3 -m pip install -r requirements.txt
python3 theory_checks.py
python3 general_theory_checks.py
```

```bash
cd 3_통계학
python3 -m pip install -r requirements.txt
python3 make_tables.py
python3 make_graduation_extension_tables.py
```

경제학 계산, 수리의 실제 주식 수치 예시, 통계 예측을 원자료부터 다시 계산하려면 **KRX 원자료를 별도로 확보**해야 합니다. [DATA_SOURCES.md](DATA_SOURCES.md)에 필요한 파일·기간·열 구조와 분야별 상세 안내를 모았습니다. 전체 논문을 조판하는 코드는 이 공개 묶음에 포함하지 않습니다.

## 결과를 읽는 범위

- 경제학의 조정액은 관측 수익률을 고정한 회계적 재구성입니다. 실제 체결 주문량이나 가격충격의 인과 추정치가 아닙니다.
- 수리의 수치 검산은 증명의 보조입니다. 격자나 유한 차수에서의 확인이 해석적 증명을 대신하지 않습니다.
- 통계는 같은 두 종목 자료에서의 의사 표본외 분석입니다. 사후 사양 선택, 사건 집중성, 겹치는 예측기간과 관련 종목 간 의존성의 한계가 남습니다.

## 재현 확인과 버전 고정

이 공개 묶음을 정리하면서 Python 구문·경로를 확인했고, 원자료가 필요 없는 이론 검산 두 개와 통계 표 생성 두 명령을 실행했습니다. 새 원자료에서 전체 모형을 다시 추정한 검증은 아닙니다. 경제학 코드는 안내 문자열만 정리했고 수리·통계 분석 코드는 보관된 v22와 같습니다.

논문에서 인용하거나 결과를 대조할 때는 이동 가능한 `main` 주소 대신 **해당 파일 묶음의 커밋 SHA**를 기록하십시오. `VERSION`은 사람이 읽는 자료 버전이고, `MANIFEST.sha256`은 이 공개 묶음 안 파일의 체크섬입니다.

## 공개 범위와 작성 보조

KRX 원자료, 날짜별 전체 목표·예측 시계열, 제출용 논문·표지·서약서, 학번·연락 정보와 내부 검토 기록은 포함하지 않습니다. 데이터 취득·정제 전체를 자동화한 저장소도 아닙니다. 따라서 코드 공개와 원자료부터의 완전한 재현 가능성을 구분해야 합니다.

연구 구성·수식 및 증명 검토·분석 코드 작성·계산 대조·문장 수정에 생성형 AI 보조가 사용되었습니다. 구체적인 범위는 각 원고의 고지와 저자가 보관한 작성 기록을 따르며, 최종 내용과 해석에 대한 책임은 저자에게 있습니다.
