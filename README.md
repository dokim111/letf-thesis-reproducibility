# 이전 재현자료 보관본

이 저장소는 과거 원고에서 인용한 코드와 실행 기록을 보존하기 위한 것입니다. 현재 원고의 재현 절차와 인용 정보는 해당 논문에 기재된 저장소를 기준으로 확인하십시오.

## 과거 버전 열람

- [고정 보관본](https://github.com/dokim111/letf-thesis-reproducibility/tree/abb2c9164f4b7c0264867ac56045cf20f4cefc2b)
- [당시 실행 안내](https://github.com/dokim111/letf-thesis-reproducibility/blob/abb2c9164f4b7c0264867ac56045cf20f4cefc2b/README.md)

과거 원고와 대조할 때에는 그 원고에 적힌 커밋을 사용하십시오. 보관된 코드의 실행에는 해당 시점의 입력자료가 필요하며, KRX 원자료는 이 저장소에 포함하지 않습니다.
